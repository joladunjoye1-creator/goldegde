# XAU/USD Pro Toolkit — GoldEdge
## Deploy to Vercel in 5 steps

### What this is
A fully installable PWA (Progressive Web App) with 6 gold trading calculators.
Works on iPhone and Android. No App Store needed.

---

### Step 1 — Upload to GitHub
1. Go to github.com and click the "+" icon → "New repository"
2. Name it: goldedge (or anything you like)
3. Make it Public
4. Click "Create repository"
5. On the next screen click "uploading an existing file"
6. Drag ALL the files from this folder into the upload area
7. Click "Commit changes"

### Step 2 — Connect to Vercel
1. Go to vercel.com (you're already logged in)
2. Click "Add New Project"
3. Click "Import" next to your goldedge repository
4. Vercel auto-detects it's a Vite project — don't change any settings
5. Click "Deploy"

### Step 3 — Wait 60 seconds
Vercel builds and deploys. You get a live URL like:
  https://goldedge.vercel.app

### Step 4 — Share with your community
Send them the link. That's it.

### Step 5 — How they install it
iPhone: Open link in Safari → Share button → "Add to Home Screen" → Add
Android: Open link in Chrome → tap banner "Add to Home Screen" → Install
